## openDialog

Renders your component in a dialog. `result` resolves what you pass to `close()`, or `undefined` on Escape and outside clicks.

<Example preview={<Try run={pickPlan}>Pick a plan</Try>}>
<include meta='title="open-dialog.tsx"'>../../components/api/open-dialog.tsx</include>
</Example>

<div className="var-table api-table">

| Option | Type | What it does |
| --- | --- | --- |
| `render` | `(props) => ReactNode` | Your content. `props.close(value)` resolves it, `props.dismiss()` resolves `undefined`. |
| `buttons` | `DialogButton[]` | Passed to `render`, for a layout of your own. |

</div>

`openDialog()` returns a handle:

<div className="var-table api-table">

| Field | Type | What it does |
| --- | --- | --- |
| `result` | `Promise<R \| undefined>` | Resolves when the dialog closes. |
| `close` | `(value: R) => void` | Closes with a value. |
| `dismiss` | `() => void` | Closes with `undefined`. |
| `update` | `(patch) => void` | Changes options of the open dialog. |
| `id` | `DialogId` | For `closeDialog(id)`. |

</div>

## Dialog

Renders in place and opens while `open` is true, so its content reads your component's state. Plain HTML inside gets the default look.

<Example preview={<EditNote />}>
<include meta='title="dialog.tsx"'>../../components/api/dialog.tsx</include>
</Example>

<div className="var-table api-table">

| Prop | Type | What it does |
| --- | --- | --- |
| `open` | `boolean` | Shows the dialog. |
| `onOpenChange` | `(open) => void` | Called with `false` on Escape and outside clicks. |
| `children` | `ReactNode` | Your content. [DialogLayout](#dialoglayout) lays it out. |
| `aria-label` | `string` | Names the dialog when there is no `DialogLayout` title. |
| `aria-labelledby` | `string` | The id of your own title. |

</div>

It also takes `modal`, `closeOnEscape`, `closeOnClickOutside`, `onKeyDown`, `unstyled` and `classNames` from the [shared options](#options-every-dialog-takes).

<div className="var-table api-table">

| Prop | Type | What it does |
| --- | --- | --- |
| `kind` | `'confirm' \| 'alert' \| 'prompt'` | Which dialog it is. |
| `open` | `boolean` | Shows the dialog. |
| `onOpenChange` | `(open) => void` | Called with `false` when any button or key closes it. |

## DialogLayout

Lays out a title, a message, your content and a row of buttons. An action whose `onClick` returns a Promise is busy until it settles. Use it in `openDialog`, `<Dialog>` and `customUI`.

<Example preview={<Try run={renameWorkspace}>Rename workspace</Try>}>
<include meta='title="dialog-layout.tsx"'>../../components/api/dialog-layout.tsx</include>
</Example>

<div className="var-table api-table">

| Prop | Type | What it does |
| --- | --- | --- |
| `title` | `ReactNode` | Heading. It names the dialog when there is no `aria-label`. |
| `message` | `ReactNode` | Text under the title. |
| `actions` | `DialogAction[]` | The buttons, left to right. |
| `children` | `ReactNode` | Your content, between the message and the buttons. |

</div>

Each action takes:

<div className="var-table api-table">

| Field | Type | What it does |
| --- | --- | --- |
| `label` | `ReactNode` | Button text. |
| `variant` | `'primary' \| 'secondary' \| 'danger'` | Button colour. Default `'secondary'`. |
| `onClick` | `(event) => void \| Promise` | A Promise makes the button busy until it settles. |

</div>

Any other button attribute, such as `type="submit"` or `disabled`, goes on the button.

## DialogHost and useDialog

Dialogs render where you place `<DialogHost />`, so they read the context above it. This site places one inside its theme provider, so the dialog below reads the theme. Switch the theme and open it again.

<Example preview={<ShowTheme />}>
<include meta='title="dialog-host.tsx"'>../../components/api/dialog-host.tsx</include>
</Example>

```tsx title="app/providers.tsx"
<ThemeProvider>
  {children}
  <DialogHost dismissKey={usePathname()} />
</ThemeProvider>
```

<div className="var-table api-table">

| Prop | Type | What it does |
| --- | --- | --- |
| `dismissKey` | `unknown` | When it changes, every dialog closes. Pass the pathname. |

</div>

Place one host. Without one, dialogs render in a root of their own and miss your context. The [Next.js recipe](/docs/recipes/next-app-router) shows where. `useDialog()` returns `confirm`, `alert`, `prompt`, `openDialog` and `closeAll`, for code that prefers a hook.

Sets defaults for every dialog. Call it once, where your app starts.

| Option | Type | What it does |

## Options every dialog takes

`confirm`, `alert`, `prompt` and `openDialog` take these.

<div className="var-table api-table">

| Option | Type | What it does |
| --- | --- | --- |
| `title` | `ReactNode` | Heading. |
| `message` | `ReactNode` | Text under the title. A string keeps its line breaks. |
| `content` | `ReactNode` | Your JSX between the message and the buttons. |
| `closeOnEscape` | `boolean` | Default `true`. |
| `closeOnClickOutside` | `boolean` | Default `true`. |
| `strategy` | `'stack' \| 'queue'` | `stack` opens on top, the default. `queue` waits its turn. |
| `modal` | `boolean` | `false` renders a plain overlay instead of a top-layer `<dialog>`. |
| `signal` | `AbortSignal` | Aborting it dismisses the dialog. |
| `onKeyDown` | `(event, close) => void` | Your own keys. `close()` dismisses. |
| `afterClose` | `() => void` | Runs once the dialog has closed. |
| `unstyled` | `boolean` | Drops the default CSS classes. |
| `classNames` | `DialogClassNames` | A class per slot. See [Styling](/docs/styling#slots). |

</div>

### customUI

`customUI` replaces the whole dialog with your content. `skin: true` puts it in the new dialog body, where plain HTML gets the default look. [Custom UI](/docs/custom-ui) has more.

<Example preview={<ShowTerms />}>
<include meta='title="custom-ui.tsx"'>../../components/api/custom-ui.tsx</include>
</Example>

<div className="var-table api-table">

| Option | Type | What it does |
| --- | --- | --- |
| `title` | `string` | Heading. |
| `message` | `string` | Text under the title. |
| `buttons` | `object[]` | Each has `label`, `onClick` and `className`. Every button closes the dialog. Default Cancel and Confirm. |
| `customUI` | `(props) => ReactNode` | Replaces the dialog content. `props.onClose()` closes it. |
| `skin` | `boolean` | The new look, with `customUI` too. Default `false`. |
| `childrenElement` | `() => ReactNode` | Renders under the message. |
| `closeOnEscape` | `boolean` | Default `true`. |
| `closeOnClickOutside` | `boolean` | Default `true`. |
| `onClickOutside` | `() => void` | Runs on a click outside. |
| `onKeypressEscape` | `(event) => void` | Runs on Escape. |
| `onkeyPress` | `(event, close) => void` | Runs on any key. |
| `willUnmount` | `() => void` | Runs before the dialog unmounts. |
| `afterClose` | `() => void` | Runs after it closes. |
| `overlayClassName` | `string` | A class on the overlay. |
| `targetId` | `string` | Renders into the element with this id. |
| `modal` | `boolean` | Native modal `<dialog>`. Default `false`. |
| `strategy` | `'replace' \| 'stack' \| 'queue'` | Default `'replace'`: a new dialog closes the open one. |
| `unstyled` | `boolean` | Drops the 3.0 classes. |
| `classNames` | `DialogClassNames` | A class per slot. |

</div>
