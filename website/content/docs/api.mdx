## Options every dialog takes

`title`, `message`, `closeOnEscape`, `closeOnClickOutside`, `strategy` (`'stack'` or `'queue'`), `modal`, `signal`, `onKeyDown`, `afterClose`, `unstyled` and `classNames`.

## openDialog, closeDialog, closeAll

`openDialog<R>({ render })` returns `{ id, result, close, dismiss, update }`. `closeAll()` dismisses every dialog, including queued ones.

## DialogHost, useDialog, ConfirmDialog

`<DialogHost dismissKey={pathname} />` renders dialogs inside your tree and closes them when `dismissKey` changes. `<ConfirmDialog kind="confirm" open onOpenChange />` is `confirm` rendered in place.

## confirmAlert (3.0 API)

`confirmAlert(options): void` takes every 3.0 option, plus `modal`, `strategy`, `unstyled` and `classNames`. Its defaults keep 3.0 behavior.

## configureDialogs

Sets app-wide defaults: `modal`, `strategy`, `closeOnEscape`, `closeOnClickOutside`, `lockScroll`, `labels`, `unstyled`, `classNames`, and separate `confirmAlert` defaults.
