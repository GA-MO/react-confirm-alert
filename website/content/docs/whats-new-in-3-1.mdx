3.1 is a minor release. Install it and your 3.0 code keeps working: `confirmAlert` and every option, the default export, the CSS path, the class names, and the timing (`onClick`, then `willUnmount`, then `afterClose`, before the click returns).

## Fixed for you

- The blur shows on every open, not only the first (#77).
- Pressing inside and releasing outside no longer closes the dialog (#92).
- Focus moves into the dialog and back (#29). Buttons show a ring for keyboard focus.
- Opening a dialog while one is open no longer logs a `createRoot` error (#82).

## New, when you want it

1. **`await confirm()`** returns the answer, so the code reads top to bottom:

<Example preview={<DeleteButton />}>
<include meta='title="delete-button.tsx"'>../../components/examples/delete-button.tsx</include>
</Example>

2. **`<DialogHost />`** inside your providers lets dialogs read context.
3. **`configureDialogs({ confirmAlert: { modal: true } })`** gives `confirmAlert` the native modal: it sits above every z-index and keeps focus inside. Check toasts and widgets that should stay above dialogs.
4. **`<Dialog open>`** renders in place when a dialog needs your component's state. See the [API](/docs/api).
5. **`customUI` still works**, and from 3.3 `skin: true` gives it the new look. See [Custom UI](/docs/custom-ui).
