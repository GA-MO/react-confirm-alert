## CSS variables

The default CSS reads every value from a variable. For `confirmAlert` the fallbacks are the 3.0 values. `--rca-title`, `--rca-border`, `--rca-ring`, `--rca-button-bg-hover` and `--rca-danger-hover` style `confirm`, `alert` and `prompt` only. The two hover colours default to `--rca-button-bg` and `--rca-danger` made 15% darker.

`--rca-width`, `--rca-padding`, `--rca-radius`, `--rca-bg`, `--rca-fg`, `--rca-title`, `--rca-border`, `--rca-shadow`, `--rca-font`, `--rca-gap`, `--rca-backdrop`, `--rca-blur`, `--rca-z-index`, `--rca-button-bg`, `--rca-button-bg-hover`, `--rca-button-fg`, `--rca-button-radius`, `--rca-danger`, `--rca-danger-hover`, `--rca-ring`, `--rca-focus-ring`, `--rca-duration`, `--rca-delay`, `--rca-easing`.

```css
:root { --rca-width: 28rem; --rca-button-bg: #111; }
```

## Dark mode

Dark mode is off until you turn it on. It doesn't follow the OS setting by itself, so it can't disagree with your app's own theme switch. Put the `dark` class or `data-theme="dark"` on an ancestor, usually `<html>`:

```html
<html class="dark">
```

To follow the OS setting instead, set the class from `prefers-color-scheme` in your theme code. Set `--rca-*` variables under your dark selector to change the dark colours.

## Slots

`classNames` takes a class per slot: `dialog`, `panel`, `body`, `title`, `message`, `actions`, `button`, `field`, `label`, `input`, `error`. Classes add up in this order: the 3.0 class (unless `unstyled`), `configureDialogs`, the call, then a 3.0 button `className`.

## Data attributes

The frame has `data-rca`, `data-state` (`open` or `closing`), `data-kind`, `data-tone`, `data-depth`, `data-topmost` and, while a button waits, `data-busy`. Every slot has `data-slot`; buttons have `data-variant`.

## Unstyled

`unstyled: true` drops every `react-confirm-alert-*` class and inline style. Behavior stays: focus, Escape, outside clicks, waiting for exit animations. With `unstyled`, lock scroll in your own CSS.

## Motion

Closing waits for animations and transitions on the frame, its `::backdrop` and the panel, so an exit transition on `[data-state='closing']` plays out. `prefers-reduced-motion: reduce` turns the default fade-in off.
