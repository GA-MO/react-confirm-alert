## Default CSS plus utilities

Import the library CSS into the `components` layer, in your main CSS file. Tailwind's `utilities` layer then wins without `!important`.

```css title="app/globals.css"
@import 'tailwindcss';
@import 'react-confirm-alert/style.css' layer(components);
```

Import it from CSS, not from JavaScript. A CSS file loaded after Tailwind's layer order would beat the utilities.

## Tailwind only

`unstyled: true` drops the default CSS, and `classNames` styles each slot. Pass the same options to `configureDialogs` to use them for every dialog.

</Example>

Use `open:grid`, not `grid`. A `display` class beats the browser rule that hides a closed dialog.
