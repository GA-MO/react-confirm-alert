description: Import the CSS into a layer so utilities win, or go unstyled.
---

## Default CSS plus utilities

Import the library CSS with `layer(components)` in your main CSS file. Tailwind's `utilities` layer then beats it without `!important`:

```css
@import 'tailwindcss';
@import 'react-confirm-alert/style.css' layer(components);
```

```tsx
confirm({ title: 'Publish?', classNames: { button: 'rounded-full bg-red-500' } })
```

Import it from CSS, not from JavaScript: a CSS file loaded after Tailwind's layer order would win over the utilities.

## Tailwind only

```tsx
configureDialogs({
  unstyled: true,
  classNames: {
    dialog: 'fixed inset-0 m-0 open:grid size-full max-h-none max-w-none place-items-center bg-transparent p-4 backdrop:bg-black/40',
    panel: 'w-full max-w-md rounded-xl bg-white p-6 shadow-xl transition data-[state=closing]:opacity-0',
    actions: 'mt-6 flex justify-end gap-2',
    button: 'rounded-md px-3 py-1.5 data-[variant=primary]:bg-zinc-900 data-[variant=primary]:text-white'
  }
})
```

Use `open:grid`, not `grid`: an author `display` beats the browser's rule that hides a closed dialog.
