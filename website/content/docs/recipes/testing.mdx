## Mock

```ts title="Vitest"
vi.mock('react-confirm-alert', () => ({
  confirm: vi.fn().mockResolvedValue(true),
}))
```

```ts title="Jest"
jest.mock('react-confirm-alert', () => ({
  confirm: jest.fn().mockResolvedValue(true),
}))
```

`confirmAlert` returns `void`, so this type-checks:

```ts
jest.spyOn(lib, 'confirmAlert').mockImplementation(() => {})
```

## Through the real dialog

jsdom has no `showModal`, so the dialog renders as a plain element with the same roles:

```ts
const result = confirm({ title: 'Delete?' })
const button = await screen.findByRole('button', { name: 'Confirm' })
await user.click(button)
expect(await result).toBe(true)
```

Jest needs CSS imports mapped:

```js title="jest.config.js"
moduleNameMapper: { '\\.css$': 'identity-obj-proxy' }
```
