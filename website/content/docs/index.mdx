import { Example } from '@/components/example'
import { DeleteButton } from '@/components/examples/delete-button'

```bash
npm install react-confirm-alert
```

Import the CSS once, for example in your root layout:

```tsx title="app/layout.tsx"
import 'react-confirm-alert/src/react-confirm-alert.css'
```

Then ask a question and wait for the answer. Press the button:

<Example preview={<DeleteButton />}>
<include meta='title="delete-button.tsx"'>../../components/examples/delete-button.tsx</include>
</Example>

`confirm()` resolves `true` or `false`. Escape, a click outside, `closeAll()` and a route change all resolve it with `false`.

## Already on 3.0

`confirmAlert(options)` works as it did in 3.0. See [What's new in 3.1](/docs/whats-new-in-3-1) for what you can adopt, one step at a time.

## Dialogs that read your providers

Place `<DialogHost />` inside your providers once. Every dialog then renders there and sees Redux, Intl, SWR and theme context.

```tsx title="app/providers.tsx"
<IntlProvider locale="th">
  <App />
  <DialogHost />
</IntlProvider>
```

Try every option in the [playground](/playground).
