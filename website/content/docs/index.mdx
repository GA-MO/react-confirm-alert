## Install

```bash
npm install react-confirm-alert
```

Import the CSS once, in your root layout. The path needs 3.1.1 or later.

```tsx title="app/layout.tsx"
import 'react-confirm-alert/style.css'
```

## Ask and wait

`confirm()` resolves `true` from the confirm button. Cancel, Escape, a click outside and `closeAll()` resolve `false`.

```tsx
import { confirm } from 'react-confirm-alert'

async function onDelete() {
  const ok = await confirm({
    title: 'Delete “Q3 report.pdf”?',
    tone: 'danger',
  })
  if (ok) await moveToTrash('Q3 report.pdf')
}
```

## Dialogs that read your providers

Place `<DialogHost />` once, inside your providers. Every dialog then renders there and reads your context, such as Redux, Intl or a theme.

```tsx title="app/providers.tsx"
<IntlProvider locale="th">
  {children}
  <DialogHost />
</IntlProvider>
```

The [Next.js recipe](/docs/recipes/next-app-router) adds `dismissKey`, so dialogs close on navigation.
